# 💬 Chat App Flutter

A real-time chat application built with **Flutter**, **Firebase**, and **BLoC/Cubit** state management.

## ✨ Features

- 🔐 User Authentication
  - Sign In
  - Sign Up
  - Firebase Authentication

- 💬 Real-time Messaging
  - Instant chat using Cloud Firestore
  - Live message updates
  - Messages ordered by timestamp

- ⚡ State Management
  - BLoC Pattern
  - Cubit
  - Event & State architecture
  - Global BlocObserver for state transition logging

- 🚨 Error Handling
  - Firebase Authentication exception handling
  - User-friendly error messages
  - Chat sending error handling

- 🎨 Clean UI
  - Responsive design
  - Modern chat interface

---

## 🛠 Tech Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- flutter_bloc (BLoC & Cubit)
- Bloc Observer
